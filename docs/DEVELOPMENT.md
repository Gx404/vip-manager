# 开发与验收

[返回首页](../README.md)

## 目录结构

    frontend/       React/Vite 看板、组件、静态 Nginx 镜像
    backend/        Express API、SQLite、迁移、备份、测试
    shared/         前后端共用类型和日期算法
    scripts/        本地启动、文档检查、代理验证和打包
    docs/           部署、使用、配置、维护和验收说明
    .github/        GitHub Actions、Issue/PR 模板
    compose.yaml    默认服务器编排

前后端使用 npm workspaces，共用根目录锁文件。不要把后端密码配置导入前端。

## Windows 本地开发

需要 Node.js 24.14.0 或更新的 24.x：

    Copy-Item .env.example .env
    # 编辑 .env 设置 ADMIN_PASSWORD
    npm ci
    npm run dev

访问 http://127.0.0.1:5173；后端是 http://127.0.0.1:3000。开发数据库独立于生产。

## 自动检查

    npm run check

它执行文档链接检查、前后端 TypeScript 检查、隔离 API 测试和前端生产构建。测试覆盖来源校验、Cookie、密码哈希、增删改、复合哈希限流、回环容错、伪造代理头、版本冲突、幂等续费、限时撤销、事务回滚、流水隔离、JSON 预览/恢复和密码重置；日期覆盖月末、闰年、时区、停机补齐、逐版本迁移、自动日期联动/自定义保留及模板；还有分类、百分比、颜色、月均折算和本地图标安全测试。

多币种测试覆盖 30 币种、v4 SQLite 原币与人民币金额无损迁入 v5、旧备份与 v2 备份恢复、手动/自动续期/撤销保留购买日汇率、流水快照不随编辑变化、分类/周期/币种总额核对和空报表。汇率查询使用受控响应测试日期参数、周末报价、缓存过期、同键合并、币对错误、未来/陈旧报价和失败重试；不把外部服务实时可用作为单元测试前提。

### 可选隔离浏览器回归

安装或复用 Playwright 1.62.1（仅测试依赖，不随生产服务运行），准备 Chromium 或 Edge，然后执行：

```sh
npm run build
node scripts/test-browser.mjs
```

测试用内存数据库和随机生成的临时账号，不读取 .env，不访问正式服务，所有增删/导入仅针对内存测试数据。覆盖真实生产前端的日期联动、模板、详情内快捷续费/撤销及未保存保护、汇率查询/手填、流水、JSON 下载/合并/覆盖、两格总览和报表，以及 320/375/390/768 像素紧凑视图；截图保存在被忽略的 outputs/browser-tests。可以设置 PLAYWRIGHT_MODULE 指向已有 Playwright 的 index.mjs，BROWSER_CHANNEL=msedge 使用现有 Edge。默认 npm run check 无需 Playwright。

生产依赖可另行运行 npm audit --omit=dev；结果会随公告变化，不代表永久安全。

## GitHub Actions

.github/workflows/ci.yml 在 push、PR 和手动运行时执行：Ubuntu/Windows 检查、Ubuntu Docker 构建、真实容器健康、静态图标、API 冒烟及重启后的自动续期，并保存无敏感数据的源码 ZIP。工作流只申请 contents: read，不使用服务器密钥、不推送镜像、不自动部署。

CI 通过不代表你的域名、证书、服务器网络或手机日历已经验证；必须看实际 Actions 结果并完成服务器验收。

## 打包

    npm run build
    npm run package

打包结果在 outputs/，白名单收集源码和文档，排除 .env、数据库、备份、日志、密钥和依赖目录。

## 服务器验收

- [ ] 两个容器 healthy，/api/health 返回 ok。
- [ ] HTTPS、域名、登录、退出、错误密码提示正常。
- [ ] 私人模式下未登录不能读取记录；公开模式展示真实会员但不返回备注，所有匿名写操作被拒绝；登录后新增、编辑、续费、删除符合预期。
- [ ] 退出后保留公开只读清单且隐藏管理按钮；空清单无示例数据。
- [ ] 无记录的分类隐藏；删除某分类最后一条记录后回到“全部”；编辑器仍可选全部分类。
- [ ] 本期剩余 50% 时条形填满一半，数字和条长一致；剩余 3 天、30 天、180 天颜色不同，不显示每格说明。
- [ ] 顶部仅有有效订阅、月均支出两格，没有 7 天内到期数量/金额。
- [ ] 点击月均支出可在手机和电脑查看每项折算：月付原价、季付÷3、年付÷12、自定义金额÷天数×30，再乘锁定汇率，并说明不是实际扣款。
- [ ] 支出分析页分类、排行、币种、周期和续费方式金额与顶部对齐，明确是预算而不是历史实付账单。
- [ ] 外币原币金额保持正确；购买日期独立保存，失败不猜测汇率，续期/撤销/备份恢复均不按当天汇率重算。
- [ ] 自动续费开启后，到期日由后台更新；关掉网页仍执行；关闭开关则不改日期。
- [ ] 重复检查不重复顺延，1 月 31 日经过二月后仍按原日期续期，停机后补齐。
- [ ] 百度网盘/OpenAI/88VIP 显示本地图标；未知名称或图标加载失败回退首字母。
- [ ] 刷新和重启后正式记录与管理员密码仍存在。
- [ ] 月末、闰年、到期当天显示正确。
- [ ] 手机分类同一行对齐且可横向滑动；图标清晰、统一尺寸且没有双重边框；页脚日期时间可见；键盘操作和日历导入提醒已实测。
- [ ] 备份已存到卷外，并在另一套实例演练恢复。
- [ ] 公网无法直连后端 3000，.env 和数据库不会被静态服务提供。
- [ ] Git 历史中没有初始化密码、令牌或真实用户数据。
- [ ] 新建时开始日期/周期联动；手工改到期日后保留；常用模板不写入虚构价格。
- [ ] 卡片/列表/提醒中心无直接续费按钮；仅详情内可快捷续费，表单未保存时禁用；30 秒可撤销，已改动/删除/自动推进的记录不能被旧撤销覆盖。
- [ ] 手动/自动流水均保留前后账期和金额，旧自动审计金额显示未知。
- [ ] JSON 导出仅管理员可用；导入先预览、并发修改拒绝覆盖；替换前有独立备份。
- [ ] 回环登录会提示代理配置问题；公网经过受控代理能识别真实客户端，不采信伪造转发头。

## 修改原则

数据库变更必须增加版本化迁移和备份/回退说明；修改续费逻辑必须补充日期测试；新增依赖要说明用途并保留许可证。不要提交占位实现、生产密码或真实数据。
